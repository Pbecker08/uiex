# Hexa Gym — Redesign de Interface

Projeto desenvolvido em dupla na disciplina de **Design Gráfico e User Experience**
do curso de Ciência de Dados e IA do Ibmec-RJ.

## O exercício

O ponto de partida foi um site institucional de hotel. A proposta era
reestruturá-lo para um segmento diferente, redefinindo identidade visual,
conteúdo e imagens — mantendo a estrutura HTML como base e trabalhando a
camada de apresentação.

Criamos a Hexa Gym, uma academia fictícia.

## O que foi feito

- Definição da identidade visual da marca: nome, paleta de cores e tom
- Reescrita do conteúdo textual, adequando linguagem e chamadas ao público
- Tratamento de imagens no Adobe: seleção, renderização e ajuste de
  proporções para as áreas do layout
- Adaptação da estrutura de páginas ao novo contexto

## Tecnologias

HTML · CSS · Adobe (tratamento de imagens)
